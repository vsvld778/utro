# Локальная версия UTRO

Доступна русская версия сайта. Английская версия временно отключена. Название бренда в текстах и изображениях заменено на UTRO. Цены указаны в рублях.

## Запуск

Нужен **Node.js 22 или новее**. Установщик: https://nodejs.org/. Дополнительные пакеты устанавливать не нужно.

1. Распакуйте архив полностью в отдельную папку.
2. На macOS откройте `start.command`, на Windows — `start.bat`.
3. Откройте **http://127.0.0.1:4173/**. Админ-панель: **http://127.0.0.1:4173/admin**.
4. Пока пользуетесь сайтом, оставляйте окно запуска открытым. Для остановки нажмите **Ctrl+C** в этом окне.

Если файл запуска на macOS не открывается, откройте Терминал в распакованной папке и выполните:

```bash
node local/server.mjs
```

Эта же команда подходит для Linux и Windows. Если сайт уже запущен, сначала остановите предыдущую копию через **Ctrl+C**. Одновременно использовать одну папку `data` двум экземплярам нельзя — это защищает изменения от перезаписи. Смена порта не снимает эту защиту.

Если порт занят **другим приложением**, а предыдущая копия сайта остановлена, можно выбрать другой порт:

```bash
UNDO_PORT=4174 node local/server.mjs
```

В Windows PowerShell:

```powershell
$env:UNDO_PORT=4174; node local/server.mjs
```

## Редактирование

Локальная админ-панель не требует входа в облачный аккаунт. Она доступна только на этом компьютере: сервер слушает адрес `127.0.0.1` и отклоняет запросы с посторонним адресом или источником.

Выберите страницу, измените текст или изображение, затем сохраните черновик. Применение изменений в админ-панели обновляет **только локальный сайт**. Цены и подключения сервисов применяются ко всем страницам.

Тексты, черновики, история версий и заявки сохраняются в `data/content.json`; загруженные изображения — в `data/media/`. Чтобы перенести изменения на другой компьютер, скопируйте **всю папку `data`**, предварительно остановив сервер. Резервную копию также делайте после остановки.

При обычном завершении блокировка данных снимается автоматически. После аварийного завершения сервер проверит, существует ли прежний процесс, и восстановит доступ, только если он уже завершён. Если состояние блокировки нельзя надёжно определить, запуск остановится с пояснением, сохранив данные.

Копия работает без интернет-соединения после установки Node.js. Платёжные страницы, портал подписок, внешняя карта и изображения по внешним URL потребуют интернет-соединения, если вы сами укажете их в настройках. По умолчанию внешние сервисы не подключены. Локальный сервер ничего не выгружает на хостинг и не отправляет письма.

Для дальнейшей разработки сохранён исходный код. Для обычного запуска и редактирования сборка не требуется.
