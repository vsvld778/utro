## Пределы проверки

Растровые изображения просмотрены на контактных листах; проблемные и некоторые групповые фотографии дополнительно просмотрены крупно. Это визуальная проверка, а не гарантия распознавания каждой микроскопической надписи. OCR в текущей среде не заработал. Пять проверок brand.test.mjs прошли. Интеграционный тест локального HTTP-сервера не смог запуститься: среда запретила открытие порта (EPERM). Поиск в SVG не обнаружил текстового UNDO; основная иконка содержит букву U.

Работа выполнена на копии, совпадающей по контрольным суммам изменяемых файлов с GitHub main 69413b0ab10894b03b7044b82ae8969b8de2c6b0. Настройки живой CMS прочитаны отдельно. Подключение к исходному серверу Sites завершилось ошибкой DNS, браузерная проверка также недоступна. Изменения сохранены в GitHub, но не опубликованы на действующем адресе Sites. Нельзя считать текущий опубликованный сайт исправленным до успешного развёртывания.

## Совместимость

Имена файлов, архивные источники, CSS-классы, ключи и произвольные пользовательские URL сохранены. Точные исходные контактные ссылки info@undogummies.com при отображении ведут в форму UTRO. Старое слово в техническом имени не является видимой надписью на фотографии. Исходные английские записи сохранены как архив; /en перенаправляется на русскую версию. Старые значения CMS нормализуются при отображении. Произвольные загруженные пользователем изображения не переписываются.
