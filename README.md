# UTRO — сайт и редактор

Русскоязычная витрина UTRO: 19 страниц, каталог, карточки наборов, корзина, блог и административная панель. Цены отображаются в рублях, количество — в шт. Английская версия временно отключена; старые адреса `/en/…` перенаправляют на русские страницы.

Сайт: https://undo-gummies-study-vsevolod.nordterma.chatgpt.site/

Админ-панель: https://undo-gummies-study-vsevolod.nordterma.chatgpt.site/admin

## Локальный запуск

Нужен Node.js 22 или новее. Подготовленные файлы витрины и редактора включены в репозиторий; для обычного запуска установка зависимостей не требуется.

```bash
node local/server.mjs
```

Откройте http://127.0.0.1:4173/ или http://127.0.0.1:4173/admin. Также доступны `local/start.command` для macOS и `local/start.bat` для Windows. Сервер слушает только локальный адрес. Для остановки нажмите Ctrl+C.

Локальные изменения сохраняются в `data/content.json`, изображения — в `data/media/`. Эта папка не публикуется. Для переноса данных остановите сервер и скопируйте папку `data` целиком. Подробнее: [инструкция запуска](local/README-local.md).

## Редактирование и сервисы

В редакторе можно менять тексты, изображения, порядок и видимость блоков, цены, настройки корзины и подключения внешних сервисов. Сохранение черновика не изменяет опубликованную витрину. История позволяет вернуть предыдущую версию.

Оплата, подписки, личный кабинет и карта магазинов подключаются собственными ссылками и настройками в разделе «Интеграции». По умолчанию платёжные операции не выполняются. Формы сохраняют заявки; автоматическая отправка писем не подключена.

## Хостинг и доступ

На текущем хостинге редактор использует вход через ChatGPT. Сервер проверяет владельца по настройке `CMS_ADMIN_EMAIL`. Данные хранятся в D1, загруженные изображения — в R2. Секреты задаются в окружении сервера и не входят в исходники.

GitHub хранит исходный код и ресурсы. Полноценная админ-панель требует серверного выполнения и хранилища; GitHub Pages самостоятельно эту серверную часть не запускает. Действующая админ-панель остаётся по ссылке выше.

## Разработка

```bash
npm ci
npm run build:local
npm run dev:local
```

`npm run build` собирает серверную версию. `npm run test:local` проверяет автономный сервер.

- `app/`, `lib/cms/` — серверная витрина, авторизация и редактор.
- `public/` — стили, шрифты, интерактивное поведение и изображения UTRO.
- `reference/pages.json` — неизменяемый архив исходной структуры undogummies.com.
- `reference/i18n/` и `scripts/build-localization.py` — русская локализация.
- `local/` — автономный сервер и готовая локальная сборка.
